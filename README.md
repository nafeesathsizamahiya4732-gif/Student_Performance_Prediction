# Student Performance Prediction System

## About the Project

This project predicts the academic performance of students using machine learning.

The system uses student details such as age, study time, absences, parental support, tutoring, and other activities to predict the student's grade class.

## Objective

The main aim of this project is to identify students who may be at risk of getting low grades so that proper support can be given to them.

## Dataset

The dataset contains student academic and personal information.

Some of the details include:
- Age
- Gender
- Study Time
- Absences
- Tutoring
- Parental Support
- Extracurricular Activities
- Sports
- Music
- Volunteering
- GPA
- Grade Class

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Machine Learning Models

The following models were used:
- Logistic Regression
- Decision Tree
- Naive Bayes
- Support Vector Machine

## Steps

1. Loaded the student dataset
2. Checked the data
3. Removed unnecessary data
4. Checked duplicate and missing values
5. Selected the required features
6. Split the data into training and testing data
7. Trained different machine learning models
8. Compared the models
9. Predicted student performance
10. Saved the best model

## Result

Different machine learning models were tested and compared. Logistic Regression gave the best accuracy among the models used.

## Conclusion

This project shows how machine learning can be used to predict student performance and help identify students who may need extra support.
